Formula
LTV = Σ (t = 1 to N) [ MonthlyNetRev × MonthlyRetention^t × (1 + r/12)^−t ]

  where:
    MonthlyGB     = Trips × FrequencyLift × AOV
                    (FrequencyLift = 1 if non-subscriber, 1.8× default if subscriber)

    MonthlyNetRev = (MonthlyGB × TakeRate)               ← PM commission
                  + (SubFee − SubDiscountPct × MonthlyGB) ← if subscriber: fee − sub discount
                  + Σ AttachRate × NetRevContribution     ← if cross-platform scope

    r = annual discount rate (cost-of-capital)
    N = horizon (months)

Key caveats this calculator surfaces: (1) "Monthly retention 91.1%" is a flow proxy [Active(t) / (Active(t-1) + New(t-1))], not true cohort retention — mixes sub and non-sub users; production version needs cohort-level user data. (2) Cross-platform attach rates and per-attach NetRev are placeholders — real numbers require user-level cross-app join (in metrics-to-collect). (3) Trips/AOV are aggregates; sub members and high-LTV cohorts likely much higher; Maintain-tier cohorts likely lower. Production version segments by cohort. (4) Take rate 12.9% is PM aggregate — varies by merchant tier (Lite 15% → Net Rev higher; Plus/Premium chains contribute different mix).
